<p>错误定律</p>
<ul>
<li>别人都不对，那就是自己的错。</li>
</ul>
<p>效果定律</p>
<ul>
<li>在伤口上落泪和在伤口上撒盐，效果是一样的。</li>
</ul>
<p>嫉妒定律</p>
<ul>
<li>人们嫉妒的往往不是陌生人的飞黄腾达，而是身边的人飞黄腾达。</li>
</ul>
<span id="more"></span>

<p>方圆定律</p>
<ul>
<li>人不能太方，也不能太圆，一个会伤人，一个会让人远离你，因此人要椭圆。</li>
</ul>
<p>口水定律</p>
<ul>
<li>当你红得让人流口水时，关于你的口水就会多起来。</li>
</ul>
<p>利用定律</p>
<ul>
<li>不怕被人利用，就怕你没用。</li>
</ul>
<p>成就定律</p>
<ul>
<li>如果你没有成就，你就会因平庸而没有朋友；如果你有了成就，你就会因卓越而失去朋友。</li>
</ul>
<p>馅饼定律</p>
<ul>
<li>当天上掉下馅饼的时候，小心地上也有个陷阱在等着你。</li>
</ul>
<p>错误定律</p>
<ul>
<li>人们日常所犯的最大错误，是对陌生人太客气，而对亲密的人太苛刻。</li>
</ul>
<p>评价定律</p>
<ul>
<li>不必好奇别人怎样评价你，想想你是怎样评价他的。</li>
</ul>
<p>葱蒜定律</p>
<ul>
<li>太拿自己当根葱的人，往往特别善于：装蒜。</li>
</ul>
<p>流言定律</p>
<ul>
<li>流言是写在水上的字，注定不持久，但是又传得飞快。</li>
</ul>
<p>害怕定律</p>
<ul>
<li>生手怕熟手，熟手怕高手，高手怕失手。</li>
</ul>
<p>难过定律</p>
<ul>
<li>为你的难过而快乐的，是敌人；为你的快乐而快乐的，是朋友；为你的难过而难过的，就是那些该放进心里的人。</li>
</ul>
<p>傻瓜定律</p>
<ul>
<li>把人家都当傻瓜，那一定是自己傻到了家。</li>
</ul>
<p>吃亏定律</p>
<ul>
<li>只要你不认为自己吃了亏，别人也就一定没占着便宜。</li>
</ul>
<p>风雨定律</p>
<ul>
<li>爱情经得起风雨，却经不起平淡；友情经得起平淡，却经不起风雨！</li>
</ul>
